# pac-man-clone-with-cpp-graphics
This is a pac-man clone made using C++ graphics. The program was written and compiled using the Code::Blocks Integrated Development Environment (IDE) with the TDM-GCC compiler. It was developed for CCE-3606 (Computer Animation and Game Development Sessional) lab project.
